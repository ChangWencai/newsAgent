<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→web | 未认证用户尝试访问管理页面 |
| client→api | 外部调用 API 端点 |
| form→server | 用户提交 POST 表单 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing | web routes | mitigate | Flask session cookie 签名 + before_request 认证钩子，未认证返回 302 |
| T-02-02 | Tampering | POST forms | mitigate | Flask-WTF CSRFProtect 自动注入和验证 CSRF token |
| T-02-03 | Information Disclosure | config/settings.py | mitigate | validate_config() 启动时检查必填项，缺失则退出，不泄露具体密钥值 |
| T-02-04 | Elevation | /login endpoint | mitigate | 密码比对不区分大小写但不日志输出密码，401 返回通用错误 |
</threat_model>
